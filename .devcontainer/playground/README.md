# quirq playground

This Codespace has qq, qqsync and the xo CLI installed. Open a terminal
(**Ctrl+`**) and follow any guide on [docs.quirq.dev](https://docs.quirq.dev/docs),
for example:

```sh
mkdir -p ~/qq-try && cd ~/qq-try
qq fetch https://github.com/quirq-ai/innernet
cd innernet && qq test
```

It is your own machine, on your GitHub account's free Codespaces allowance.
`xo login` signs in your own account. Delete the Codespace at
https://github.com/codespaces when you are done.
