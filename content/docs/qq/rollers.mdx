<Callout type="info">
  **Today:** nothing lands on its own. Dependabot PRs and toolchain roll PRs
  both stop at an open pull request for a person to merge (see

## What it rolls

| Roller | Moves | How |
|---|---|---|
| Toolchain pins | `[toolchains.*]` in each `infra/repo.toml` | to the digests toolchains promoted, through `qqsync` |
| Lockfiles | Python requirements, `pnpm-lock.yaml` | Dependabot, configured from `rollers.toml` |

Which repos get which roller, and how often, is infra-config
`config/rollers.toml`.

## Lockfile updates

Each covered repo gets two generated files from
`generated/github/<repo>/`: `.github/dependabot.yml`, and
`.github/workflows/qq-roll-land.yml`, which turns on auto-merge for a clean
Dependabot PR. The check is
[`src/qqroll/land_check.py`](https://github.com/quirq-ai/rollers/blob/main/src/qqroll/land_check.py).

A roll is clean only when Dependabot made exactly one commit, it changes at
most 20 existing dependency files, every changed line is a version, and it
bumps one dependency by a patch or minor version (below 1.0 a minor counts
as major). Anything else leaves the PR to a person.

```sh
# regenerate generated/
qqroll dependabot --infra-config ../infra-config --write
# check only: exit 1 if stale (presubmit runs this)
qqroll dependabot --infra-config ../infra-config
```

## Toolchain pins

The roller moves every repo's `[toolchains.*]` pins to the digests in
toolchains' `promoted.toml`, so a roll changes just the pin and its
`version` label.

- It only moves pins a manifest already has. It never adds a toolchain.
- It stays inside the org-wide pin in infra-config `kinds.toml` (python
  `3.14`, node `24`). Moving that pin is a policy change for suraj.
- A pin it leaves alone is reported and makes the command exit 1.
- Before writing, it checks each new pin again and fails closed: the digest
  must match, and `gh attestation verify` must find provenance from
  toolchains' build workflow on `main`.

```sh
# edit one local manifest
qqroll roll --toolchains ../toolchains --manifest infra/repo.toml --infra-config ../infra-config
# dry run: checks and diffs, opens nothing
qqroll rotation --infra-config ../infra-config --toolchains ../toolchains
```

The `roll-toolchains` workflow runs the rotation weekly (Monday 06:23 UTC),
on a `toolchain-promoted` dispatch, and by hand. It opens or refreshes one
PR per repo on the branch `qq-roll/toolchains`, as the quirq rollers App.

## What keeps auto-land off

| Roller | Waiting on |
|---|---|
| Lockfiles | a gate no workflow can fake, which needs org rulesets (not on quirq-ai's GitHub Free plan) or a check from a non-Actions app; and the `dependabot/**` branch rule, which gate leaves off |
| Toolchain pins | nothing technical: toolchains' `promotion-gate` has been required since 2026-10-09. Turning on auto-merge for rolls is suraj's call |

## Files and schedules

| Thing | Where |
|---|---|
| Roller config | infra-config `config/rollers.toml` |
| Generated Dependabot files | `generated/github/<repo>/` |
| Toolchain roll | `roll-toolchains` workflow, weekly |
