## The pointers

| Pointer | What it names | Who moves it |
|---|---|---|
| `lkgr` | the newest `main` commit whose required post-submit builders are all green | `lkgr` workflow, every 10 minutes |
| `channels/canary` | lkgr's commit, after the daily canary passes | `canary` workflow, daily |
| `channels/dev` | declared, off in v0 | |
| `channels/stable` | suraj promotes; v2 | |

"Green" is the gardener's definition. A missing signal holds lkgr where it
is.

Since 2026-10-09 only the release executor App can push `release-state`
(gate's `qq-release-state` ruleset). Undo is the break-glass pair in gate's
[`docs/apply-settings.md`](https://github.com/quirq-ai/gate/blob/main/docs/apply-settings.md).

## The daily canary

The `canary` workflow runs daily at 06:17 UTC for every repo with a canary
release builder. The first failing stage holds the canary, and the previous
one stays.

| Stage | What |
|---|---|
| select, build | lkgr's commit, built through recipes |
| verify, fuzz smoke | the full test suites, then again with 1,000 examples |
| deploy, probe | start it on the CI runner and run every `health.toml` probe |
| promote | the executor moves `channels/canary` |

A pipeline error is not a hold, until 3 such runs for the same commit.
`canary-watchdog` restarts a missed run. Each day's report is an issue
labelled `canary-report`.

## What you do with it

```sh
# see every channel
qqrelease channel show --state ...
# compute lkgr
qqrelease lkgr --config <infra-config checkout> --state <state dir> [--publish] [--dry-run]
# roll a channel back (or run the channel-rollback workflow)
qqrelease channel rollback --config ... --state ... --repo NAME --channel canary --reason "..." --from COMMIT
```

A rollback points the channel at the newest earlier commit it was never
rolled back from; nothing is rebuilt.

**Release a hold** with the `canary-release-hold` workflow.

## Files and schedules

| Workflow | When |
|---|---|
| `lkgr` | every 10 minutes, off the hour |
| `canary` | daily, 06:17 UTC |

| `channel-rollback`, `canary-release-hold` | on demand |
