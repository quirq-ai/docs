  <JourneyStep id="get" n={1} title="Get the repo">
    `qq fetch` clones a repo and runs `qq sync` in it, which downloads the
    repo's pinned toolchains and checks each against its digest. Make a
    folder for it first, and go into the clone after:

    `mkdir -p ~/qq-try && cd ~/qq-try`

    `qq fetch https://github.com/quirq-ai/innernet`

    `cd innernet`
  </JourneyStep>
  <JourneyStep id="show" n={2} title="See what it builds">
    A repo is a list of **targets**, each with a **kind** such as `node-app`
    that tells qq how to build and test it. Ask `qqsync` rather than reading
    `infra/repo.toml` yourself. innernet has one target, `app`.

    `qqsync show`
  </JourneyStep>
  <JourneyStep id="test" n={3} title="Build and test it">
    `qq test` builds every target, then tests it, one line per step. Read
    each line as *result, target, step*.

    `qq test`
  </JourneyStep>
  <JourneyStep id="results" n={4} title="Read the results">
    Everything a run produces lands in `.qq/out`: `results.json` for scripts
    and agents, one log per step in `logs/`, and JUnit XML in `junit/`.

    `ls .qq/out .qq/out/logs`
  </JourneyStep>
  <JourneyStep id="run" n={5} title="Run it">
    `qq run` runs a command with the repo's pinned toolchains first on
    `PATH`. innernet starts at http://127.0.0.1:3470 on your machine. The
    replay's first line, `not synced here`, is there only because the
    recording machine could not run `qq sync`; after `qq fetch` you will not
    see it.

    `qq run "pnpm start"`
  </JourneyStep>
</Journey>

## Run it for real

**Run it for real** opens a GitHub Codespace: a Linux machine in your
browser, made from this docs repo, with qq, qqsync and the xo CLI already
installed. Every command runs there, so you can go off the guide and try
anything. You need a GitHub account, and it works best on a computer. It is
your own Codespace, on your account's monthly Codespaces allowance (free up to
its limit; past it, GitHub bills your account if it has a payment method), and
you can delete it when you are done. It holds no key or token of quirq's.
