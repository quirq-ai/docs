## Names you will see

- **XO Space**: the app your agents work in. Run it on your computer or in the cloud.
- **XO Cloud**: XO Space run for you at app.xo.builders. Some pages call it Cloud Space, Managed
  Cloud Space, XO Managed Cloud or XO Swarm.
- **XO and quirq**: XO Labs makes XO Space. quirq is the name on our GitHub org and website, so
  you will see both.
- **a quirq**: a proposed unit for the work agents deliver ([the idea](/docs/quirq)). XO Space
  does not count quirqs yet.
- **qq**: the tools we use to build, test and land our own code. Releases through qq are not
  live yet.
