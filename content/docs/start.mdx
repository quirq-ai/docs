## Names you will see

- **qq**: quirq infra, and its command line. It builds, tests and lands code in quirq's repos.
- **a quirq**: a proposed unit for the work agents deliver ([the idea](/docs/quirq)). Nothing
  counts quirqs yet.
- **quirq**: also the name on our GitHub org and website.
