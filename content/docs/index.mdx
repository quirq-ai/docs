## Quick Answers

<Accordions>
	<Accordion title="What is qq?">
		qq (quirq infra) is how quirq builds, tests and lands code, and how it will ship it. You
		write code as usual, human or agent. qq decides whether it lands, keeps `main` green and
		moves tested commits into release channels. See [the qq guide](/docs/qq).
	</Accordion>
	<Accordion title="Can I use qq on my Mac?">
		Partly. Toolchains are fetched for Linux x86_64 only. On a Mac, `qq sync` stops with
		`no pin for platform`, and you install the pinned Python 3.14.8 or Node 24 yourself.
		See [Use qq on your machine](/docs/qq#use-qq-on-your-machine).
	</Accordion>
	<Accordion title="Is qq the same as quirq?">
		No. **qq** is the infra and its command line. **a quirq** is a
		[proposed unit for agent work](/docs/quirq). Nothing counts quirqs yet.
	</Accordion>
	<Accordion title="Where are the XO Space docs?">
		XO Space, XO Cloud and their agents are documented at
		[docs.xo.builders](https://docs.xo.builders).
	</Accordion>
</Accordions>
