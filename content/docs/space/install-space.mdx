<Lead>
  Run one command in the folder where you keep your projects. It installs XO
  Space and starts it. You bring your own coding agent.
</Lead>

## What you need

- Linux or macOS. On Windows, use WSL.
- `git` and `curl`. You don't need Docker.

The installer sets up Python for you. Some features need another tool, and Space
tells you at startup if one is missing:

| Tool | Used for |
|---|---|
| A signed-in agent CLI or gateway | Running prompts through that agent |
| `node` and `npm` | Installing Node-based agent CLIs |
| `gh` | GitHub issue polling and project backup |
| `rclone` | Drive and OneDrive connectors |
| `gpg` | Encrypted backup and restore |

## Install and open

Open a terminal in your projects folder and run:

```bash
curl -fsSL https://quirq.ai/install | sh
```

Then open [http://localhost:5002/space/](http://localhost:5002/space/), or the
address the installer prints. **Keep the terminal open.** Space runs there, and
`Ctrl-C` stops it.

<Callout type="info">
  This installs `main`, the release branch. To try the newer UI shown in these
  guides, use
  `curl -fsSL https://quirq.ai/install | QUIRQ_SOURCE_REF=development sh`.
  It can include changes that are not released yet.
</Callout>

## Add your agent

Space starts with Claude Code as its chat agent, but it does not install the
agent or sign you in. Install and sign in to your agent the usual way. For
Claude Code:

```bash
npm install -g @anthropic-ai/claude-code
```

Then open **Setup** in Space to check your folders and pick your agent. See
[Setup](/docs/space/space-walk/setup). If Space can't find your agent, see
[runtime discovery](/docs/space/auto-detection).

## Start, update or remove

Run these from your projects folder:

```bash
# Start again without updating
./xo-space/install.sh

# Update, then start
curl -fsSL https://quirq.ai/install | sh

# See what removal would do, then remove
./xo-space/uninstall.sh --dry-run
./xo-space/uninstall.sh
```

An update skips a checkout that has local changes or is on another branch, and
the startup message says so. Removing keeps your project folders. Space adds no
system service, scheduled job or login item.

## Install from a clone

If the one-line command doesn't work for you, clone and install:

```bash
git clone https://github.com/quirq-ai/xo-space.git
cd xo-space
./install.sh
```

This uses your checkout as it is. The folder you start from becomes your
workspace unless you pick other folders in Setup. To change Space's own code,
see [contributing](/docs/space/contributing).

## What it creates

```text
workspace/
├── xo-space/      Space's code, its .env settings and Python
├── .quirq/        logs, history, settings and saved secrets
├── .xo/           workspace records
└── my-project/    your projects
```

The server log is `.quirq/logs/quirq.log`. Your agents keep their own
conversations in their usual folders.

## Settings

The installer writes `xo-space/.env` once and keeps your later edits. **Setup
shows the settings Space is really using**, so check there first. Common ones:

| Setting | Default | Meaning |
|---|---|---|
| `XO_PROJECTS_ROOT` | The folder you installed from | Each folder inside it is a project |
| `QUIRQ_STATE_ROOT` | `.quirq` in that folder | Logs, history and settings |
| `AGENT_NAME` | `claude_code` | Chat agent; also `codex`, `openclaw`, `hermes`, `antigravity` |
| `PORT` | `5002` | Preferred port |
| `HOST` | `127.0.0.1` | Address Space listens on |

To set one when you install:

```bash
curl -fsSL https://quirq.ai/install | PORT=8080 sh
```

Keep the state folder outside your project folders.
