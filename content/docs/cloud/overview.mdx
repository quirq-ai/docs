<Lead>
  XO Space is open source. You can run it on your own computer, or let **XO
  Cloud** run it for you on a cloud machine at
  [app.xo.builders](https://app.xo.builders). Both run the same XO Space.
</Lead>

## Which one to pick

| | **On your computer** | **XO Cloud** |
|---|---|---|
| **Good for** | Watching the agents you already run, working offline | Not installing anything, running agents remotely, sharing a project |
| **How to start** | [Install Space](/docs/space/install-space) | Sign up at [app.xo.builders](https://app.xo.builders) |
| **Where you edit** | Your own editor and terminal | VS Code in your browser |
| **Where data lives** | On your computer, unless you turn on [usage reporting](/docs/space/space-walk/setup#usage-reporting) | On your cloud machine |

Either way, you bring your own model key or subscription.

## Start on XO Cloud

1. [Create an account](/docs/cloud/create-account).
2. [Choose an agent](/docs/cloud/choose-an-agent).
3. [Launch your first agent](/docs/cloud/launch-first-agent).
4. [Manage your machine](/docs/cloud/manage-space).

Then [set up models, data and chat apps](/docs/setup). Words you don't know are in
the [Glossary](/docs/glossary).
